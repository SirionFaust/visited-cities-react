Visited Cities App

A web application built with React and Vite, styled using Tailwind CSS, designed to track and manage cities you have visited or plan to visit.
Features

    Dynamic addition of new cities using an interactive form component (CardForm).

    Real-time form state management powered by the useState hook.

    Responsive city cards (Card) supporting images, descriptions, and visit status indicators (visited / not visited).

    Modern and clean UI layout styled with Tailwind CSS.

Technologies Used

    React

    Vite

    Tailwind CSS
